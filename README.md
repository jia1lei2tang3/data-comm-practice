# 数据通信与网络 · 练习题

面向《数据通信与网络》课程的刷题小工具。共 362 题：358 道单选 + 4 道填空。
覆盖第 1–5 章作业、课后测试题与课堂练习题。每题附简洁解析。

## 功能

- 按章选题，作业/课后测试/课堂练习可自由组合
- 顺序或随机练习，可开启选项乱序
- 答完立即判对错，显示正确答案与解析
- 错题自动进错题本，可只练错题；错题回顾附解析
- 进度保存在本机浏览器，无需注册登录
- 电脑支持键盘 1–6 选答，回车下一题

## 使用方法

**电脑**：双击 `index.html`，用任意浏览器打开。

**手机（安卓）**：把整个文件夹传到手机，用浏览器打开 `index.html`。
也可以用 Chrome 打开后选"添加到主屏幕"，之后像 App 一样使用。

**手机（苹果）**：iOS 限制本地打开网页文件，建议把项目部署到网上，
用 Safari 打开链接，再选"添加到主屏幕"。

## 部署到网上（可选）

项目是纯静态文件，随便一个静态托管都行。以 GitHub Pages 为例：

1. 在 GitHub 新建仓库，把这 5 个文件传上去
2. 仓库 Settings → Pages → 选 main 分支根目录 → 保存
3. 得到链接 https://用户名.github.io/仓库名/ ，发给同学即可

部署后手机可安装到桌面、断网也能用（已内置离线缓存）。
